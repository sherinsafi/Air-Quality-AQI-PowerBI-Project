# 🌫️ Real-Time Air Quality Analysis (AQI)

## 📌 Project Overview
This project analyzes real-time air pollution data across Indian monitoring stations.
The dataset does not directly provide AQI, so a derived AQI was created using major pollutants.

## 🧰 Tools Used
- Microsoft Excel (Data Cleaning & Transformation)
- Power BI (Dashboard & Visualization)
- DAX
- Pivot Tables

## 📊 Dashboards
- AQI Overview Dashboard 
- Pollutant Deep Dive Dashboard
  
   [View Dashboard Report](Air_Quality_Analysis_Report.pdf)

## 📂 Dataset Source
Government of India – data.gov.in  
https://data.gov.in/resource/real-time-air-quality-index-various-locations

- Cleaned_Air_Quality.xlsx

## 🔍 Key Insights
- Identified top polluted cities using AQI
- PM2.5 and PM10 are major contributors
- AQI category distribution across stations
